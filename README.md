# Smart Dustbin using Machine Learning YOLOv8n

## Project Description
This project implements a Smart Dustbin system using Machine Learning to automatically
identify waste and assist in proper waste management. The model classifies trash using
image-based detection techniques and can be integrated with hardware for real-time use.

The complete model training and testing were performed using Google Colab.

## Features
- Automatic trash detection using ML
- Image-based waste classification
- Can be integrated with IoT / embedded systems
- Reduces human intervention in waste management

## Technologies Used
- Python
- Machine Learning
- OpenCV
- NumPy
- TensorFlow / PyTorch
- Google Colab

## Files in Repository
- Untitled5.ipynb : Model training and evaluation notebook
- requirements.txt : Python dependencies
- Model file : Trained weights (if included)

## How to Run
1. Install required libraries:
   pip install -r requirements.txt
2. Open the notebook:
   Untitled5.ipynb
3. Run all cells to train or test the model
